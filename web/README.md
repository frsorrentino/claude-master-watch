# Web app di claude-master

La stessa app del telefono nel browser. Sul Chromebook usa il relay locale (`127.0.0.1`), ovunque altro Firebase. Piano:
`../docs/plans/2026-10-05-web-app-piano.md`. Svelte 5 + Vite, TypeScript.

- `npm test`: i test, sulle fixture di `../contract`
- `npm run dev`: in sviluppo
- `npm run build`: in `dist/`, la cartella che serve il relay
