# Verifica dal vivo: casa della master, widget Master, voce, passaggi (notte del 02/10)

Piano: `docs/plans/2026-10-02-telefono-notte-piano.md`. Una riga per prova; si spunta solo provata sul telefono.

| # | Prova | Atteso | Esito |
|---|---|---|---|
| 1 | Aprire l'app da chiusa | Si apre sulla scheda **Master**: in alto «Per te» (se c'è qualcosa) e il **Quadro**, sotto la chat della master con la barra di scrittura | |
| 2 | Toccare il Quadro | Si apre il **Quadro completo** (la Panoramica di ieri) in un foglio dal basso | |
| 3 | Scorrere la chat della master verso l'alto | «Per te» e il Quadro si chiudono; tornando in fondo si riaprono | |
| 4 | Una riga di «Per te» (es. contesto ≥ 80 %) | Il tasto fa l'azione (Handoff e riavvio manda il prompt alla sessione) | |
| 5 | Master chiusa | La casa mostra Quadro, «Per te» e «La master non è aperta» con **Riapri** | |
| 6 | Gesto indietro da una sessione, e «Tutte le sessioni» | Si esce dalla sessione e non si riapre | |
| 7 | Menu ≡ | «Master», «Quadro», «Sessioni», «Diario», Impostazioni | |
| 8 | Toccare l'anello del contesto in una sessione | Foglio con «Scrivi l'handoff e riparti pulita», «Compatta», «Passa alla finestra da 1M» se serve | |
| 9 | Menu ⋮ di una sessione → «Fai controllare alla master» | Il prompt compare nella chat della master; «Chiesto alla master» | |
| 10 | Ultima risposta con la riga `Prossimi:` | Sotto la risposta «Prossimi» e i consigli; tocco = nel campo; pressione lunga = invio; la riga non si vede nel testo | |
| 11 | Campo vuoto a sessione ferma | Il suggerimento di Claude Code attenuato nel campo e «Usa» | |
| 12 | ▶ su una risposta con grassetto e codice | Nessun «asterisco»; il codice annunciato; il testo si mostra a paragrafi con quello letto in evidenza | |
| 13 | Toccare un paragrafo durante la lettura | La lettura riparte da quel paragrafo | |
| 14 | Impostazioni → Voce | Elenco delle voci italiane, «Prova», la scelta resta dopo il riavvio | |
| 15 | Riquadro dei passaggi chiuso | Due righe al massimo, contorno leggero con la barretta a sinistra; si apre al tocco | |
| 16 | Lista dei widget del launcher | Due widget con anteprima vera: quello di ieri e **Master** | |
| 17 | Posare il widget Master (4×2 e 4×4) | Testata con stato, ultimo messaggio o domanda, barra «Scrivi alla master»; nel 4×4 i chip delle sessioni | |
| 18 | Barra del widget Master | Si apre il foglio con la tastiera; l'invio arriva alla master e il foglio si chiude | |
